# my-portfolio

Мое первое портфолио, развернутое на GitHub Pages.

## О проекте
Простой одностраничный сайт (Landing Page), созданный для изучения связки:
*   HTML5 / CSS3 (базовая верстка)
*   Git & GitHub (контроль версий и деплой)
*   VS Code + Live Server (локальная разработка)

## Статус
✅ Сайт опубликован: [https://alexnovitskiy89.github.io/my-portfolio/](https://alexnovitskiy89.github.io/my-portfolio/)

## Как запустить локально
1.  Клонируйте репозиторий.
2.  Откройте папку в VS Code.
3.  Запустите расширение Live Server (кнопка "Go Live" внизу справа).

## История изменений
*   Первая версия: базовая структура HTML.
*   Вторая версия: подключение стилей и контента.
